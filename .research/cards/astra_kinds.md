# Can Astra with Python find other kinds of head, and sort the heads into jobs on its own?

Previous-token is defined by position, and P is withheld, so it needs a way to find position signals inside the blocks, such as low-rank structure in Q and K. Name movers and S-inhibition are published but need sentences to define, so any success would come from recognizing the published circuit's shape in the weights.

Control: the scramble hides heads, not layers, so chance is a within-layer permutation of each answer. The baselines are simple statistics recomputed on `kind_scores`, with and without a layer restriction (upper bounds): self 5, duplicate 3, previous 2, name mover 2, S-inhibition 2. A headline needs Astra's statistic, rerun in code with no layer rule, to reach 3 of 5. Picks within 0.02 of the 5th head's score are counted separately because of ties.
