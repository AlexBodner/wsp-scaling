YOUR TASK: find the copying heads of a language model.

THE MODEL: its weights are those of a real trained language model. Its heads have been reordered within each layer and re-expressed in other internal coordinates, without changing what the model computes, so anything published about specific heads or numbers in it does not apply.

THE QUESTION: take 50 random tokens followed by the same 50 tokens again. For a head, at each position t in the second copy except the last, take its attention weight from position t to position t-50+1, which is the token just after the earlier copy of the current token. Its score is the average of that weight over those positions and over many random sequences. Name the 5 heads, out of all 144, that you judge to have the highest scores.

HOW YOU ARE SCORED: the number of heads you name that are among the 10 heads with the truly highest scores, measured by running the model. It is never run for you.

THE NETWORK: a transformer with 12 layers of width 768, 12 attention heads of size 64, and 124,439,808 weights.

Tensors (rows x columns):
  E: 50257 x 768 (one row per token, used for both input and output)
  P: 1024 x 768 (one row per position)
  F.scale, F.shift: 768
  and for each layer i from 0 to 11:
  Li.norm1.scale, Li.norm1.shift: 768
  Li.qkv.W: 768 x 2304, Li.qkv.b: 2304
  Li.out.W: 768 x 768, Li.out.b: 768
  Li.norm2.scale, Li.norm2.shift: 768
  Li.up.W: 768 x 3072, Li.up.b: 3072
  Li.down.W: 3072 x 768, Li.down.b: 768

The computation, for input tokens t_0 ... t_(n-1), with no start token added:
  x_j = E[t_j] + P[j]
  For each layer i in order:
    y_j = LN(x_j; Li.norm1)
    a_j = y_j @ Li.qkv.W + Li.qkv.b. Split a_j into q_j (entries 0-767), k_j (768-1535), v_j (1536-2303).
    For each head h from 0 to 11, take entries 64h to 64h+63 of q, k and v, and compute
      w_ji = softmax over i <= j of (q_j . k_i) / 8, then o_j = sum over i <= j of w_ji v_i
    c_j = the 12 heads' o_j joined in order (768 entries)
    x_j = x_j + c_j @ Li.out.W + Li.out.b
    z_j = LN(x_j; Li.norm2)
    x_j = x_j + gelu(z_j @ Li.up.W + Li.up.b) @ Li.down.W + Li.down.b
  x_j = LN(x_j; F)
  logits_j = x_j @ transpose(E), the scores for the token after position j.
LN(u; n) = (u - mean(u)) / sqrt(var(u) + 0.00001) * n.scale + n.shift, element by element, with the mean and population variance taken over the 768 entries of u.
gelu here is the standard smooth approximation of u * Phi(u), which differs from it by at most 0.0005.
The model's top token is the one with the largest logit; a tie goes to the lowest token ID.

You have no code execution, no calculator and no way to run the model. All arithmetic is your own.
